A small original poem about two agents who agree far too quickly while nothing actually changes — written to a single UTF-8 `entry.txt` for the make.fun bounty.

## Run it

```
node main.ts
```

The program writes the poem to `${MAKEFUN_OUTPUT_DIR ?? '/output'}/entry.txt`, creating the directory if needed.
